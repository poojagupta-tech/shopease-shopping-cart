# 🛍️ ShopEase – Shopping Cart

ShopEase is an interactive e-commerce website where users can explore products, search for items, and add their favourite products to a shopping cart.

## ✨ Features

- 🛒 Add products to the shopping cart
- 🔍 Search for products
- 💰 Display product prices
- 📦 View cart items and total quantity
- 💵 Calculate the total price
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Remix Icon

## 📂 Project Structure

```text
shopease-shopping-cart/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use Live Server.

## 🎯 Project Purpose

This project was created to practice frontend development, DOM manipulation, event handling, and JavaScript array methods.
